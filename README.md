# Study

Python 学习练习仓库

## 2026.8.20

### 学习内容

- `if / elif / else` 判断
  - if-elif-else 语句的执行顺序是从上到下
  - 满足一个条件后，后面的条件不会继续执行

- `format()` 和占位符 `{}`

- `int()`
  - 将字符串转换成整数

- `input()`
  - 获取用户输入
  - `input()` 返回的数据类型默认是字符串

- 布尔类型
  - `True`
  - `False`

### 遇到的问题

- 一开始不知道为什么 `input()` 不需要使用 `print()`
  - 理解：`input()` 本身会显示提示信息并获取用户输入

- 理解了 `input()` 返回的是字符串

- 一开始不知道 `format()` 的作用
  - 理解：`format()` 可以给字符串中的占位符 `{}` 填入变量
